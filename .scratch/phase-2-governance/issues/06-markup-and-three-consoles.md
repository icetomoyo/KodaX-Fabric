# 06 — 对客倍率与三套控制台

**What to build:** 超级管理员设全局倍率。Request 写入当时对客金额。平台控制台看成本/对客/毛利。企业与团队控制台只看成本。三套路由互不混登。P1 `/admin` 种子超管进平台控制台。

**Blocked by:** 02 — 四角色、成员、企业控制台人事；05 — 熔断、限流、预算

**Status:** ready-for-agent

- [ ] 改倍率后新 Request 用新倍率；旧 Request 对客金额不变
- [ ] 平台控制台能下钻企业/Team 看见毛利；企业/团队控制台 JSON 无对客字段
- [ ] `/platform`、`/enterprise`、`/team` 按角色进入；混登 403
- [ ] 企业控制台无线路/密钥入口；团队控制台按角色藏「加开发者」
