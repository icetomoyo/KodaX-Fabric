# TokenHub v0.0.5 规划

| 项 | 内容 |
|---|---|
| 版本 | `v0.0.5` |
| 基线 | `a51d302`（v0.0.4） |
| 状态 | **已实施并完成本地验证（2026-08-07）** |
| 目标 | 新增工单系统，支持员工提交工单、管理员统一查看 |

## 1. 版本范围

本版本提供基础工单能力：

1. 员工提交工单，并查看自己提交的工单。
2. 管理员查看全部员工工单及详情。
3. 工单提交后不可编辑或删除，避免问题描述被修改。

本版不包含工单回复、指派、附件、通知和处理状态流转。

## 2. 员工端

新增 `/me/tickets` 页面：

- 提交字段：标题、问题描述。
- 标题长度为 1～100 个字符，问题描述长度为 1～5000 个字符。
- 提交成功后生成唯一工单编号，并显示提交时间。
- 员工只能查看自己的工单列表和详情，不能查看其他员工的工单。

## 3. 管理端

新增 `/admin/tickets` 页面：

- 展示工单编号、标题、提交员工、部门和提交时间。
- 支持按标题、工单编号或员工姓名查询。
- 列表按提交时间倒序排列，每页 10 条。
- 管理员可打开详情，查看完整问题描述和员工信息。

## 4. 数据与接口

新增 `tickets` 表，至少包含：

```text
id, ticket_no, employee_id, subject, content, created_at
```

接口规划：

| 接口 | 作用 | 权限 |
|---|---|---|
| `POST /api/me/tickets` | 提交工单 | 员工 |
| `GET /api/me/tickets` | 查看自己的工单列表 | 员工 |
| `GET /api/me/tickets/:id` | 查看自己的工单详情 | 员工 |
| `GET /api/admin/tickets` | 查看全部工单 | 管理员 |
| `GET /api/admin/tickets/:id` | 查看工单详情 | 管理员 |

问题描述按纯文本展示，禁止直接渲染 HTML。接口不返回密码、API Key 等无关敏感信息。

## 5. 验收标准

- 员工可以成功提交工单，并在自己的列表中看到该工单。
- 员工访问他人工单时返回 404，避免泄露工单是否存在。
- 管理员可以分页查询全部工单并查看详情。
- 普通员工访问管理端工单接口返回 403。
- 标题或问题描述为空、长度超限时返回 400。
- 数据库迁移、服务端测试和前端构建均通过。
