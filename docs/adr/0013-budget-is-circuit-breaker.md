# 预算是熔断器，允许短暂超卖

精确「永不越过」需要预占，那是对外计费的事，不在 P2。事后扣减 + 阈值检查在并发下一定能把余额打穿。

P2 的 Budget 停的是已经超了之后的新请求（402），不是账房。没配 = 无限。Project 与全局、日与月都是独立跳闸，不是「内层花完花外层」的瀑布。软限制只打响应头。窗口按 Asia/Shanghai 的日或月切。打上游之前检查；回来后按各 Attempt 成本之和事后扣减。进程内计数，不把 Redis 变成网关单点。

预算挂在 Team，企业级可选。按成本计，不按对客金额。没有压所有企业的平台总闸——中转站老板用价格看收益，不用一根绳子停掉全部客户。
