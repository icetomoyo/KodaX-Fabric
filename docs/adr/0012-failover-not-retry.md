# 只做同 model 的 Channel failover，一次入口仍是一粒 Request

同一 Channel 上重试 429/5xx 会和调用方自己的重试叠乘，也把中间失败藏起来，破坏「上游错误看起来像直连」。跨 Channel 换路才是「单渠道下线客户端无感知」。

一次入口 HTTP 仍是账本里的一粒 Request（ADR-0001）。内部换 Channel 不新开粒。Failover 已产生的上游消耗必须能进账，不能只记下最后一次成功。同一 Channel 的重试留给调用方。

只在向调用方写出任何响应（状态行、头、体）之前换路。一旦开始写，不再 failover。触发：传输失败、超时、429、5xx、401/403、404。400/422 不换——那是调用方 body，换了会把坏请求放大。一次入口最多 3 次 Attempt（含第一次）；单次 Attempt 默认超时 30s。这两个数全局可配，不按 Channel 配。
