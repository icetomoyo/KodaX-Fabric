### 本版本范围

**做**

- OpenAI Chat Completions / Anthropic Messages 双端点零转换
- SSE 透传、客户端断开停上游、结束用厂家 `usage` 计量
- 数据模型预留 VK → 池（本版池内可以只有一条路）

**不做**

- 渠道池 failover、限流熔断、预算、缓存、运营审批
- Token ROI / Commerce / SSO
