## FEATURE_009: 独立部署收口

> **状态**：**Completed**
> **版本**：v0.1.0 → Released v0.1.0

### 1. 需求概述

生产 gateway 必需 REDIS_URL 且启动 PING。`/health` 同时检查 PG+Redis，失败 503。`/live` 不依赖外部。Redis 故障时有硬预算的请求 fail-closed。管理员用 ADMIN_TOKEN 配置实体。同一把 fab- VK 走 OpenAI 与 Anthropic。

### 2. 影响范围

`hub.RedisCache` / `RedisBudget` / `RedisLimiter`；store CRUD；`cmd/mockprovider`；`deploy/compose.yaml`；`deploy/scripts/*`。熔断仍 `Limiter` 本地。

### 3. 技术方案

- Redis 前缀 `th:cache:`、`th:rpm:`、`th:budget:`、`th:lease:`。
- RPM/预算 Lua 原子；缓存 stats 用 HINCRBY 跨进程。
- 启动：OpenRedis + NewRedisCache/Budget/Limiter。单元测试可用 Memory + miniredis。
- mock-provider 仅本地/CI，密钥 `mock-openai` / `mock-anthropic`。

### 4. 接口契约

- `GET /live` 进程存活；`GET /health` readiness（postgres/redis/version/commit）。
- `ADMIN_TOKEN` 管理 `/admin/v1/providers|pools|channels|virtual-keys`。
- `CACHE_TTL` 默认 1h。`IMAGE_TAG` 发布用不可变 tag。

### 5–6. 实现与验收

`TestRedisSharedCacheAndRPMAndBudget`、`TestRedisProviderRPMSharedAcrossServers`、`TestRedisBudgetConcurrentNoPierce`、`TestRedisBudgetFailClosed`、`TestAdminCRUDChainBothEndpoints`、`TestAdminPartialUpdateRetainAndClear`、`TestAdminPatchChannelRuntimeSync`；compose smoke + backup/restore。
