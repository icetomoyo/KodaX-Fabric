# v0.2.0 Feature Design

## FEATURE_001: 调度画布查看并释放渠道 Key

### 需求概述

企业管理员打开调度画布（仅本企业）。点击渠道 Key 节点后高亮关联路径，并展开抽屉展示绑定范围、5 小时/周积分用量、当前连到这把 Key 的员工。可将已绑定的渠道 Key 释放回资源列表；自建渠道共享池没有 `credential_bindings` 行，不提供释放。超管保留原画布，并同样能查看/释放。

### 影响范围

- `server/src/routes/admin/key-bindings.ts` — `org_admin` 可读画布；`POST .../credentials/:id/release`
- `server/src/lib/relay/binding.ts` — `releaseCredentialBinding` / `loadBindingEnterpriseId`
- `web/src/views/admin/KeyBindingsView.vue` — 渠道 Key 抽屉与释放
- `web/src/layouts/AdminLayout.vue`、`web/src/router/index.ts` — 企业管理员入口

### 技术方案

渠道 Key 绑定仍是 `credential_bindings` 一行一 Key。释放即删除该行，Key 回到未绑定池（资源列表）。企业管理员只能释放绑定落在本企业范围内的 Key。图接口为渠道 Key 附带积分用量与绑定范围。

### 接口契约

- `GET /api/admin/key-bindings` — `admin` / `org_admin`；企业管理员强制 `enterpriseId = session.enterpriseId`
- `GET /api/admin/key-bindings/live` — 同上
- `POST /api/admin/key-bindings/credentials/:id/release` — 成功返回 `{ credentialId, productLineId, scopeType, scopeId }`；未绑定 409；跨企业 403

### 实现步骤

- 画布对 `org_admin` 开放并按企业过滤
- 渠道 Key 节点点击展开用量抽屉
- 释放绑定并刷新资源列表
- 回归：部门管理员 403；企业管理员不能看/放其它企业的绑定

### 验收标准

- 企业管理员侧栏可见「调度画布」，只看到本企业调度
- 点击已绑定渠道 Key 可看到绑定范围、积分用量、使用该 Key 的员工
- 「释放到资源列表」后该 Key 出现在右下角资源抽屉，画布上不再连着原员工/部门
- 部门管理员不能打开画布或调用释放接口
