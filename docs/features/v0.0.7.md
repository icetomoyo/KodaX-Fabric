# v0.0.7 — VK 月预算与流式 Token 估算

## Part A — 版本级叙事

VK 按自然月隔离的整数 Token 软/硬闸：软阈值只警告（响应头 / 流式 Trailer + 路由审计），硬阈值在打上游前 402 且上游 0 次。读完 body 后按「输入估算 + `max_tokens`/`max_completion_tokens`」原子预留；无输出上限则预留全部剩余额度（同时只放一个未知上限请求）。硬闸：`settled + in-flight observed + remaining reservation + new need <= hard`（Snap 的 `Used+Reserved` 即当前总暴露）。未打上游则释放预留且不记账；已发上游后断流/网络失败保留估算。官方 usage 校准不双计、不 clamp；若官方超出声明预留，账本记录超限并挡住后续。热账内存实现（`HotBudget`），0.1.0 用 Redis 热账 + PG 对账替换，不引入 Commerce / 模型价目表。

## FEATURE_007: VK 月预算软硬闸与流式估算

> **状态**：**Completed**  
> **版本**：v0.0.7 → Released v0.0.7

### 1. 需求概述

按 VK + `YYYY-MM`（注入时钟可测月切换）记账。金额单位 = `int64` Token，禁止 float。软限默认硬限的 80%。硬拒 402、软警告不拦截。流中估算、官方 usage 校准、断流保留估算。OpenAI `total_tokens` / `prompt+completion` 与 Anthropic `input+output`（含 `message.usage`）都认。

### 2. 影响范围

`HotBudget` / `MemoryBudget`；`virtual_keys.monthly_token_hard|soft`；`route_decisions.budget_*`；relay 读完 body 后 `Reserve`；`writeUpstream` 按 chunk `Observe`。不改 0.0.1–0.0.6 默认（hard=0 不限）。

### 3. 技术方案

- `Reserve` 返回 lease；`Observe` 增加 pending 并从该 lease remaining 扣减；`Settle` 用官方值替换本 lease pending 并释放 remaining；未发上游 `Release`。准入检查 `used+pending+reserved`。
- 无 `max_tokens` / `max_completion_tokens`：预留全部剩余额度。大 prompt 超过余额直接 402。
- 估算：SSE `content`/`text` 按 `(runes+3)/4`（至少 1）。官方值到达则整笔替换本次 est。
- 流式先声明 Trailer `X-Fabric-Budget-Used` / `X-Fabric-Budget-Soft`，结束或断流后写最终值。
- 断流审计用 2s background context，不依赖已取消的 request context。
- 0.1.0：本接口换成 Redis 预留 + PG 月账对账；价目与人民币属 Commerce，仍不进本模块。

### 4. 接口契约

- 硬拒 `402` `code=budget_exceeded`（Anthropic 同文案）。
- 头：`X-Fabric-Budget-Used` / `X-Fabric-Budget-Month` / `X-Fabric-Budget-Soft: 1`；流式 Trailer 同 Used/Soft。
- `GET /health/budget` → `{month, budgets:[{vk_id,used,settled,reserved,month}]}`（按 vk/month 稳定排序）。
- 审计 `budget_over`：官方 usage 超出本次预留。

### 5–6. 实现与验收

T1：`TestObserveConsumesRemainingAndGatesNext`、`TestObserveOverHardBlocksAll`、`TestBudgetConcurrentNoPierce`（`Used+Reserved<=hard`）、`TestBudgetSoftWarning`、`TestBudgetHardRejectZeroUpstream`、`TestBudgetLargePromptRejects`、`TestBudgetNoChannelReleases`、`TestBudgetCircuitOpenReleases`、`TestBudgetProviderLimitReleases`、`TestBudgetMonthRollover`、`TestStreamBudgetGrows`、`TestOfficialUsageCalibratesNoDouble`、`TestStreamAbortKeepsEstimate`、`TestStreamCrossSoftTrailer`、`TestAnthropicOfficialUsage`。
