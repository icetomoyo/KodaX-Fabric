# v0.0.2 — 上游钥匙柜

## Part A — 版本级叙事

### 版本目标

管理员能把官方 Key 加密存进网关；同一家可以挂多把并轮转；废掉的 Key 不再被选。

切法：[../token-hub-slices.md](../token-hub-slices.md) **0.0.2**。  
手测对照：[../TokenHub_VISION.md](../TokenHub_VISION.md) **#10 #12 #13 #14**。

### 本版本范围

**做**（切片原文）

- 官方 Key 加密入库
- 同一家多把轮转
- 401 / 额度能停用

**手测抓手**

- 管理员录入两把官方 Key，打流会摊
- 废 Key 不再被选

**不做**

- VK 过期、模型白名单产品化（0.0.3）
- 同模型多渠 failover、路由审计（0.0.4）
- 申请审批、响应缓存、Key 自动周期轮换产品化（0.0.8；#11）
- Token ROI / Commerce / SSO / 管理控制台全量

规格与票由 `/to-spec`、`/to-tickets` 填写，本文件 Add 时不写实现。
